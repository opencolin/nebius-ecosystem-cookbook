Explore agent workflows

  • Agent cost comparison — examine the steps and cost of an agent run.
  • Competitive intelligence agent — research a company and its competitors.
  • Pull request reviewer — inspect code changes with an agent workflow.
  • OpenCrewBot — try a team of bots in one chat interface, including a credential-free mock mode.

Each example lists its required service keys. For example, the Tavily agent also needs a TAVILY_API_KEY.

Adapt and evaluate

When you have a working example, explore model evaluation, production log collection, fine-tuning, and distillation.

For a guided session, open the workshop index. For current platform behavior, refer to the Token Factory documentation.
