Cookbook / APIs

API and SDK examples

Call open models on Nebius Token Factory through its OpenAI-compatible API, or connect a framework you already use.

Start with environment setup. Each notebook lists its dependencies and model configuration.

Example Purpose Dependencies
Native API Make a direct request with the OpenAI SDK requirements.txt
Comparing models Run the same text prompt across models and save answers, time, and token usage requirements.txt
LiteLLM Use Token Factory through LiteLLM requirements-litellm.txt
aisuite Call Token Factory through a provider interface requirements-aisuite.txt
LlamaIndex Use chat and embeddings in a LlamaIndex workflow requirements-llamaindex.txt

Also see batch inference and guided JSON output.

Run a notebook

From this directory, create a Python environment and install the requirements for the notebook you chose:

uv venv --python 3.12
source .venv/bin/activate
uv pip install -r requirements.txt
uv pip install jupyterlab
python -m jupyter lab

Use the corresponding requirements file for the other notebooks. Keep your API key in the environment or in the recipe's local .env file.
